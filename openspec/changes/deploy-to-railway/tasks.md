## 1. Repository Setup

- [ ] 1.1 Fork `NeosiaNexus/SitePing` to your GitHub account via GitHub UI
- [ ] 1.2 Clone your fork locally: `git clone git@github.com:<your-username>/SitePing.git`
- [ ] 1.3 Copy the `.opencode/` and `openspec/` directories from this local repo into the cloned fork
- [ ] 1.4 Create a new branch: `git checkout -b deploy-to-railway`
- [ ] 1.5 Verify the full repo builds: `bun install && bun run build`
